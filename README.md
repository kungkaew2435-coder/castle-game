# เกมสร้างปราสาท

เว็บแอปบันทึกคะแนนงานและคะแนนสอบในรูปแบบเกม นักเรียนสร้างปราสาท 3 มิติจากคะแนนของตัวเอง ใช้เหรียญพิเศษซื้อของตกแต่ง และแลกไอเท็มกับเพื่อนช่วงเปิดหมู่บ้าน

- หน้าเว็บ: GitHub Pages
- ฐานข้อมูลและการเข้าสู่ระบบ: Firebase (แพ็กเกจ Spark ฟรี)
- ครูและผู้ดูแลเข้าด้วยบัญชี Google นักเรียนเข้าด้วยบัตร QR

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ |
| `js/main.js` | โค้ดทั้งหมดของแอป |
| `js/config.js` | ค่าเชื่อมต่อ Firebase และชื่อโรงเรียน (แก้ไฟล์นี้ไฟล์เดียว) |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล |

---

## ติดตั้งครั้งแรก (ประมาณ 20 นาที)

### 1. สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com แล้วกด **Add project / สร้างโปรเจกต์** ตั้งชื่อ เช่น `castle-game` (ไม่ต้องเปิด Google Analytics)
2. ในหน้าโปรเจกต์ กดไอคอน **`</>`** (Web) เพื่อเพิ่มเว็บแอป ตั้งชื่อเล่นอะไรก็ได้ ไม่ต้องติ๊ก Firebase Hosting
3. คัดลอกค่า `firebaseConfig` ที่ได้ แล้ววางแทนค่าในไฟล์ `js/config.js` (ชื่อโรงเรียนใน `SCHOOL.name` เว้นว่างได้)

### 2. เปิดการเข้าสู่ระบบ

1. เมนู **Build → Authentication → Get started**
2. แท็บ **Sign-in method** เปิด 2 อย่าง
   - **Google** (ใส่อีเมลติดต่อ แล้วกด Save)
   - **Email/Password** (เปิดเฉพาะช่องแรก ไม่ต้องเปิด Email link) ใช้กับบัตร QR ของนักเรียน
3. แท็บ **Settings → Authorized domains** กด Add domain แล้วใส่ `ชื่อบัญชีGitHub.github.io`
4. แท็บ **Settings → User actions / Sign-up quota** ถ้ามี ให้เพิ่มจำนวนการสร้างบัญชีต่อชั่วโมงเป็น 1000 ก่อนนำเข้านักเรียนจำนวนมาก (ค่าเริ่มต้นจำกัดไว้ประมาณ 100 บัญชีต่อชั่วโมง ถ้าเกิน ระบบจะหยุดแล้วให้กด "สร้างบัญชีที่ค้าง" ภายหลัง)

### 3. สร้างฐานข้อมูล

1. เมนู **Build → Firestore Database → Create database**
2. เลือกตำแหน่ง `asia-southeast1 (Singapore)` แล้วเลือก **Production mode**
3. แท็บ **Rules** ลบของเดิมออก วางเนื้อหาไฟล์ `firestore.rules` ทั้งไฟล์ แล้วกด **Publish**
4. แท็บ **Data** สร้างเอกสารตั้งค่าผู้ดูแลระบบ
   - กด **Start collection** ตั้งชื่อ `config`
   - Document ID: `app`
   - เพิ่ม field `adminEmails` ชนิด **array** ใส่อีเมล Google ของผู้ดูแลระบบ (เพิ่มได้หลายคน)
   - เพิ่ม field `term` ชนิด **string** เช่น `ภาคเรียนที่ 2/2569`

### 4. เปิดเว็บด้วย GitHub Pages

1. push ไฟล์ทั้งหมดขึ้น repo บน GitHub
2. ใน repo ไปที่ **Settings → Pages** เลือก Source: **Deploy from a branch**, Branch: `main` โฟลเดอร์ `/ (root)` แล้วกด Save
3. รอ 1–2 นาที เว็บจะเปิดได้ที่ `https://ชื่อบัญชี.github.io/ชื่อrepo/`

## เริ่มใช้งาน

1. **ผู้ดูแลระบบ** เปิดเว็บ กด "เข้าสู่ระบบด้วย Google" ด้วยอีเมลที่ใส่ใน `adminEmails`
2. แท็บ **นำเข้ารายชื่อ** ดาวน์โหลดแม่แบบ วางรายชื่อจากงานทะเบียน แล้วอัปโหลด ตรวจผล กดบันทึก ระบบจะสร้างบัญชีนักเรียนให้ทีละคน (อย่าปิดหน้าเว็บระหว่างสร้าง)
3. แท็บ **บัตร QR** เลือกห้อง ดาวน์โหลดไฟล์บัตร เปิดในเบราว์เซอร์ แล้วกดพิมพ์
4. **ครู** เข้าสู่ระบบด้วย Google ครั้งแรกจะขึ้น "รอผู้ดูแลระบบอนุมัติ" ผู้ดูแลไปที่แท็บ **อนุมัติครู** แล้วกดอนุมัติ ครูรีเฟรชหน้าก็เข้าใช้งานได้
5. ครูสร้างรายวิชา เลือกระดับชั้นและห้องที่สอน ตั้งเกณฑ์คะแนน เพิ่มรายการงาน แล้วเริ่มให้คะแนนได้เลย
6. **นักเรียน** เปิดเว็บ กด "สแกนบัตรด้วยกล้อง" หรือ "อัปโหลดรูปบัตร" ถ้าใช้มือถือของตัวเอง ให้ติ๊ก "เครื่องส่วนตัว" เพื่อไม่ต้องสแกนทุกครั้ง เครื่องของห้องเรียนจะออกจากระบบเองเมื่อไม่ใช้งาน 10 นาที

ผู้ดูแลระบบเป็นครูผู้สอนได้ด้วย กดปุ่ม "ไปหน้าครู" มุมขวาบน

## ความปลอดภัยและข้อควรรู้

- **บัตร QR คือรหัสผ่าน** ใครได้รูปบัตรไปก็เข้าแทนได้ ถ้าบัตรหายหรือสงสัยว่ามีคนใช้แทน ให้กด **ออกบัตรใหม่** บัตรเดิมจะใช้ไม่ได้ทันที ส่วนปุ่ม "พิมพ์บัตร" ใช้ QR เดิม
- กฎใน `firestore.rules` บังคับที่ฝั่งเซิร์ฟเวอร์ นักเรียนแก้คะแนนเองไม่ได้ ซื้อของได้เฉพาะเมื่อเหรียญพอ เห็นปราสาทเพื่อนเฉพาะช่วงเปิดหมู่บ้าน และเห็นเฉพาะขั้นปราสาท ไม่เห็นคะแนนตัวเลข
- **ราคาไอเท็ม** อยู่ 2 ที่ คือ `ITEMS` ใน `js/main.js` และฟังก์ชัน `prices()` ใน `firestore.rules` ถ้าแก้ราคา ต้องแก้ทั้งสองที่ แล้ว Publish rules ใหม่
- ไม่มีการเก็บคะแนนปลายภาคในระบบ ใช้เป็นเกณฑ์คำนวณกลุ่มเสี่ยงอย่างเดียว ครูกรอกปลายภาคในไฟล์ Excel ที่ส่งออก
- ครูผู้สอนที่อนุมัติแล้วเห็นรายชื่อนักเรียนทั้งโรงเรียน และพิมพ์บัตรได้ (ตามที่ตกลงให้ครูผู้สอนพิมพ์บัตรได้)
- นักเรียนที่ลาออกให้ตั้งเป็น "ไม่ใช้งาน" แทนการลบ คะแนนยังเก็บไว้

## โควตาฟรีของ Firebase (Spark)

อ่านข้อมูลได้ 50,000 ครั้ง/วัน และเขียน 20,000 ครั้ง/วัน พอสำหรับโรงเรียนขนาดกลาง ถ้าใช้ทั้งโรงเรียนพร้อมกันหลายร้อยคนแล้วเกินโควตา ระบบจะหยุดชั่วคราวจนถึงเที่ยงคืน (เวลาแปซิฟิก) ดูการใช้งานได้ที่ Firestore → Usage

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บขึ้น "ยังไม่ได้ตั้งค่า Firebase" | ยังไม่ได้วางค่าใน `js/config.js` |
| กด Google แล้วขึ้น `auth/unauthorized-domain` | เพิ่มโดเมน `xxx.github.io` ใน Authentication → Settings → Authorized domains |
| ผู้ดูแลเข้าแล้วขึ้น "รอผู้ดูแลระบบอนุมัติ" | อีเมลใน `config/app → adminEmails` สะกดไม่ตรง หรือยังไม่ได้สร้างเอกสารนี้ |
| ขึ้น "ไม่มีสิทธิ์ทำรายการนี้" | ยังไม่ได้ Publish `firestore.rules` หรือใช้ไฟล์ rules เวอร์ชันเก่า |
| สร้างบัญชีนักเรียนหยุดกลางทาง | ติดโควตาสร้างบัญชีต่อชั่วโมง รอสักพักแล้วกด "สร้างบัญชีที่ค้าง" ในแท็บห้องเรียนกลาง |
| เปิดกล้องสแกนไม่ได้ | เบราว์เซอร์ต้องอนุญาตกล้อง และต้องเปิดผ่าน https (GitHub Pages เป็น https อยู่แล้ว) หรือใช้ "อัปโหลดรูปบัตร" |
