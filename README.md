# ฟาร์มพิชิตคะแนน

เกมฟาร์มสะสมคะแนนสำหรับนักเรียนมัธยม (GitHub Pages + Firebase) · พัฒนาโดย Kru.Kungkaew

## กติกาเกม
- คะแนนในวิชา = ความก้าวหน้าของฟาร์ม (ขั้น 0–10) ปลดล็อกแปลงผัก เล้าไก่ คอกแกะ คอกหมู-ม้า บ่อปลา
- ปลูกผัก/เลี้ยงสัตว์ → เก็บผลผลิตเข้าโกดัง → ส่งรายการขายให้ครู → ครูกดรับซื้อ ได้เหรียญพิเศษ
- เหรียญพิเศษใช้ซื้อสัตว์และของตกแต่ง ราคารับซื้อครูปรับได้ที่ ตั้งค่าวิชา
- เสาร์-อาทิตย์เปิดเยี่ยมฟาร์มเพื่อน: รดน้ำผัก/ให้อาหารสัตว์ ครั้งละ +5 เหรียญ โควต้า 3 ครั้ง/คน/วัน ฟาร์มหนึ่งรับการช่วยแต่ละอย่างได้วันละครั้ง
- หน้าแรกแสดงอันดับเหรียญพิเศษและสถิติการขาย ท้ายเทอมผู้ที่ได้มากสุดรับรางวัลจากครู

## การเข้าใช้งาน
- นักเรียน: สแกนบัตร QR
- ครู: รหัสผู้ใช้งาน + รหัสผ่านที่ผู้ดูแลสร้างให้ (แท็บ "บัญชีครู")
- ผู้ดูแลระบบ: Google (อีเมลใน config/app.adminEmails)

## ตั้งค่า
1. คัดลอก `firestore.rules` ไปวางที่ Firebase Console → Firestore → Rules แล้ว Publish
2. เปิด Authentication: Email/Password และ Google
3. ใส่ค่าใน `js/config.js`
4. เปิด GitHub Pages จากสาขา main
